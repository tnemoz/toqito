## Description
Fixes #1546. The `is_positive_definite` function now uses the `is_hermitian`  function instead of `np.array_equal` to deal with potential inaccuracies of BLAS implementations. The new function also has an `rtol` and an `atol` parameters that are passed down to `is_hermitian`.

## Changes
<!--Notable changes that this PR has either accomplished or will accomplish. Feel free to add more lines to the itemized list
below. -->

  - [x] `is_positive_definite` now uses `is_hermitian`, with newly added tolerance parameters.
  - [x] A test that doesn't pass the current implementation of `is_positive_definite` but passes with this new implementation has been added.
  - [x] The workarounds for the tests written in #1544 have been removed. This simplifies the code, and ensures that this workaround isn't needed anymore with this new implementation.
